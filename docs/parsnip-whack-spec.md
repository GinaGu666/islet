# 项目名称：防风草保卫战 (Parsnip Whack)

**开发目标**：使用单文件 HTML5 (HTML + CSS + Vanilla JS / Canvas) 构建一个无需外部图片/音频素材、纯代码绘制（Emoji/矢量图形 + Web Audio API 合成音效）即可直接运行的完整休闲小游戏。

## 1. 屏幕布局与网格系统

- **画布尺寸**：自适应屏幕，核心游戏区居中（建议逻辑分辨率 600x800，适配 PC 鼠标与移动端触摸）。
- **顶部 HUD 栏**：显示【剩余时间（初始 60.0s）】、【当前得分】、【连击倍率 Combo (x1 ~ x5)】。
- **核心农田区**：`3 x 4` 或 `4 x 4` 的网格（共 12 或 16 块土地）。每个格子有明显的圆角矩形土地背景。
- **底部操作栏**：
  - 醒目的**【工具切换开关 / 大锤充能按钮】**（同时支持键盘 `Space` 空格键快捷切换，以及鼠标右键直接挥锤）。
  - 狂暴能量条（连续砸中小人积攒能量）。

## 2. 核心交互与状态机（关键逻辑，防操作冲突）

为了避免“想拔草结果砸烂菜”或“想砸人结果没切武器”的挫败感，设计**双模式交互**：

- **默认模式【手套/拔草模式】**：
  - 点击/划过成熟防风草 -> 拔出得分。
  - **智能防呆**：在拔草模式下，如果玩家直接点击已经钻出来的“种地小人”，自动视为“惊吓推搡”（小人眩晕 0.5 秒但不会被打飞，提示玩家切换大锤），或者提供**“一键大锤模式”**。
- **切换模式【大锤模式】**（按空格键 / 点击底部大锤按钮 / 鼠标右键）：
  - 光标变为巨大的木锤图标。
  - 点击“种地小人” -> **完美命中！** 触发击飞动画、加高分、加时间。
  - 点击“未拔出的防风草” -> **误伤惩罚！** 防风草被砸扁销毁，清空当前 Combo 倍率，屏幕显示 `-Combo` 提示。
  - 点击“空土地” -> 挥空，播放“呼——”的破风声，无惩罚但有 0.2s 挥锤后摇。

## 3. 实体生命周期与数值设定

每个网格格子（Tile）同一时间只能处于以下状态之一：

1. **EMPTY（空地）**：持续 `1.2秒` 后自动进入 `GROWING`。
2. **GROWING（发芽中）**：持续 `0.8秒`（显示小绿芽动画），随后进入 `READY`。
3. **READY（成熟防风草）**：
   - **普通防风草 (80% 概率生成)**：拔出 `+10分 * Combo`。拔出瞬间有 **30% 概率**在原地刷出 `FARMER_NORMAL`。
   - **黄金防风草 (15% 概率生成)**：带金色光晕粒子，拔出 `+50分 * Combo`。拔出瞬间 **100% 概率**在原地刷出 `FARMER_HELMET`。
   - **炸弹芜菁 (5% 概率生成)**：紫黑色冒烟，拔出不加分，触发 **1.0秒眩晕**（屏幕边缘变红，玩家无法操作）。
4. **FARMER（种地小人侵入中）**：
   - **普通小人 (`FARMER_NORMAL`)**：血量 `1`（1锤砸飞），命中 `+100分 * Combo`，奖励 `+1.5秒` 倒计时。
   - **铁锅头盔小人 (`FARMER_HELMET`)**：血量 `2`。第 1 锤砸飞铁锅（变为普通小人并重置逃跑时间），第 2 锤砸飞本人，命中 `+250分 * Combo`，奖励 `+3.0秒` 倒计时。
   - **小人行为AI**：钻出后停留 `2.5秒`（头顶有进度条/感叹号倒计时）。若超时未被砸飞，小人会偷走周围 1 格成熟防风草并钻回地底，扣除玩家 `50分` 并重置 Combo。

## 4. 狂暴大锤机制 (Fever Mode)

- 每砸飞 1 个小人积攒 `34%` 能量，连续砸飞 3 个小人自动激活 **5秒狂暴模式**。
- **狂暴效果**：大锤体积变大 2.5 倍（判定范围扩大为 3x3 区域，一锤砸一片），无视铁锅防御一击必杀，且**不会误伤防风草**。

## 5. 视听反馈与打击感 (Juice)

- **纯代码音效 (Web Audio API)**：不需要外部 mp3，用振荡器合成以下音效：
  - 拔草：高频短促的“啵”声 (Pop)。
  - 挥锤命中：低频重击 + 滑稽的音调上扬 (Duang!)。
  - 砸中铁锅：清脆的金属敲击声 (Clang!)。
  - 小人出现：滑稽的警报双音。
- **视觉特效**：
  - **顿帧 (Hitstop)**：大锤命中瞬间，画面逻辑暂停 `50ms`，增强打击厚重感。
  - **屏幕震动 (Screen Shake)**：命中瞬间画布产生 `4px` 的随机高频抖动，持续 `150ms`。
  - **粒子效果**：拔草飞出泥土颗粒；砸中小人时小人旋转缩小飞出屏幕，同时冒出飘字（`+100!`, `CRIT!`, `+1.5s`）。
