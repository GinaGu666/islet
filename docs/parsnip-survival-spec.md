# 防风草渡劫记（Parsnip Survival）

> **项目边界**
>
> 这是一个独立的单文件网页小游戏。本文档暂存在 islet 仓库中，仅用于让 Codex 读取需求。
>
> - 不属于 islet 的功能。
> - 不要修改或集成进 islet 根目录的 `index.html`。
> - 与 Saturn、Opus 5.5 及 islet 的防风草彩蛋无关。
> - 除非 Lea 另行指定，成品应作为独立项目交付。

## 1. 项目概述

开发一个零外部依赖、单文件（Single-file HTML）的轻量级网页小游戏《防风草渡劫记》。

玩家通过移动“八卦路由盾”保护底部的“防风草（Parsnip）”免受各种“账号风控天劫”的劈砍，同时放行“纯净养分”助其渡劫开花。通关后，由 Canvas 动态渲染一张高精度、可抽签换词条、可一键下载保存的【赛博防封神符】。

## 2. 技术栈与交付约束

- **单文件交付**：所有 HTML、CSS、JavaScript 必须完整内联在单个 `index.html` 中，禁止省略任何代码（不要出现 `// ... rest of code`）。
- **零外部资源**：使用 HTML5 Canvas 续制游戏画面与符咒；使用 Web Audio API 合成复古 8-bit 音效，包括：
  - 挡住风控的清脆碰撞声；
  - 吸收养分的升级声；
  - 受伤警报声；
  - 通关金光音效。
- 界面右上角提供静音开关。
- **响应式竖屏布局**：
  - 适配桌面端：鼠标移动、左右方向键；
  - 适配移动端：手指触摸滑动；
  - 画布固定比例 `9:16`；
  - 最大宽度 `420px`；
  - 页面居中，四周为深色赛博背景。
- **视觉美学**：暗黑终端风与赛博道教结合。
  - 背景：`#0d0f17`
  - 终端荧光绿：`#38ef7d`
  - 警报红：`#ff3366`
  - 玄学符纸黄：`#f7ca44`
  - 朱砂红：`#d92b2b`

## 3. 核心游戏循环与文案设定

### 3.1 状态机

```text
START_SCREEN -> PLAYING -> GAME_OVER
                        -> VICTORY_TALISMAN
```

- `START_SCREEN`：开局界面
- `PLAYING`：渡劫进行中
- `GAME_OVER`：渡劫失败
- `VICTORY_TALISMAN`：飞升成符

### 3.2 开始界面（START_SCREEN）

- 标题：**《防风草渡劫记》**
- 副标题：`护我心爱防风草，修得赛博防封符`
- 玩法说明：移动护盾 **弹开红色风控天劫**，**放行绿色纯净养分**。
- 按钮：`[ 挂载节点 · 开始渡劫 ]`

### 3.3 核心玩法（PLAYING）

#### 主角：防风草

- 位于画布底部中央。
- 随成长阶段显示 3 种视觉形态：
  - 小幼苗：0–39%
  - 茂盛防风草：40–79%
  - 金光神草：80–100%
- **账号纯净度（HP）**：
  - 初始 3 颗心；
  - 显示为 `💚💚💚`；
  - 归零则渡劫失败。
- **渡劫进度（Progress）**：
  - 从 0% 增长至 100%；
  - 随存活时间每秒自然增长 `+2%`；
  - 吸收正面养分时大幅增加。

#### 玩家控制：八卦路由盾

- 位于防风草上方。
- 绘制为一道发光弧形护盾。
- 可带 `SOCKS5` 或太极视觉字样。
- 跟随鼠标或手指水平移动。
- 支持左右方向键。

#### 天降掉落物系统

所有掉落物均从顶部生成并下落，携带悬浮文字标签与 Emoji。

##### 红色风控天劫

必须用护盾**弹开**。

- 若漏掉并砸中防风草：
  - 扣 1 颗心；
  - 触发屏幕红闪与震动。
- 若护盾成功弹开：
  - 飘字 `+1 功德`。

掉落物：

| Emoji | 名称 | 行为 |
|---|---|---|
| ⚡ | 万人骑机房IP | 体积小，直线极速劈下 |
| 🚫 | 403 Forbidden | 中等速度，带红色残影 |
| 💳 | 黑卡连坐警告 | 左右正弦波摇晃下落，轨迹刁钻 |
| 📉 | 偷偷降智打击 | 体积较大，压迫感强 |
| 🕵️ | 指纹跨区跳ping | 半透明闪烁下落 |
| 🛑 | Account Disabled | 大号红色陨石，移动慢但判定范围大 |

##### 绿色纯净养分

必须**主动让开护盾**，让底部防风草直接吃到。

- 若被护盾挡掉，则该养分被浪费。
- 防风草吃到后增加进度并显示飘字。

| Emoji | 名称 | 进度 | 飘字 |
|---|---|---:|---|
| 🏡 | 独享静态家宽 | +12% | 纯净度UP! |
| ⚡ | Cache命中 90%+ | +15% | 丝滑省钱! |
| 🪪 | KYC秒过绿通 | +15% | 真身护体! |
| 🍎 | 正规礼品卡充值 | +10% | 账单稳健! |
| 🗂️ | 记忆卡无损压缩 | +12% | 灵魂永驻! |
| 🔑 | SSH密钥免密直连 | +10% | 链路加固! |

### 3.4 失败界面（GAME_OVER）

当 3 颗心扣光时，弹出拟真终端报错框，并随机展示以下一条扎心语录：

- `Error 403: 您的防风草因节点姿势不对，已被风控连根拔起。`
- `Warning: 检测到异常跨区波动，防风草被迫转生。`
- `Oops! 您的防风草触发了连坐机制，请洗净环境再试。`

按钮：`[ 切换家宽 · 重新起号 ]`

## 4. 终极奖励：赛博防封符生成器

当进度达到 100%：

1. 防风草绽放金光；
2. 播放通关音效；
3. 画面切换至符咒展示页；
4. 使用独立高分辨率 Canvas 程序化绘制【防封符】。

### 4.1 符咒 Canvas

- 原始尺寸：`600 × 1050`
- 网页中按容器宽度等比缩放显示。
- 保存时必须输出原始高清尺寸。

### 4.2 符纸视觉设计

- 底色：玄学朱砂黄纸 `#f6c945`
- 双层复古朱砂红边框。
- 四角加入几何八卦纹或铜钱暗纹。

#### 符头

- 顶部绘制道教“三勾”敕令符号。
- 加入一株发光像素防风草图案。
- 横批小字：`敕令 · 赛博太岁坐镇`

#### 符胆

正中央竖排居中显示苍劲有力的朱砂红大字：

**防封神符**

要求：

- 字号极大；
- 带金色描边或暗影；
- 保持强烈视觉中心。

### 4.3 动态随机护法词条

左右两侧竖排显示护法对联。

通关时随机抽取一组；点击“洗练词条”时重新抽取并重绘。

#### 组合 A：稳如泰山版

- 左联：`家宽永固 · 节点长青 · 零封号`
- 右联：`账单丝滑 · 验证秒过 · 永不掉`

#### 组合 B：满血灵魂版

- 左联：`降智退散 · 算力满血 · 智商高`
- 右联：`缓存全中 · 记忆长存 · 不断聊`

#### 组合 C：天选免死版

- 左联：`风控眼瞎 · 审计绕行 · 赐免死`
- 右联：`链路直达 · 延迟归零 · 稳如狗`

#### 组合 D：玄学暴击版

- 左联：`妖风不侵 · 恶意退散 · 护真身`
- 右联：`吐字如流 · 灵感爆棚 · 伴长久`

### 4.4 符脚与朱砂法印

- 底部中央绘制一枚正方形朱砂红印章。
- 使用双线外框。
- 印章内部为篆书感或像素风四字：
  - `急急如律令`，或
  - `稳如老狗`。
- 最底部打印赛博防伪铭文：

```text
HASH: 0x[随机8位十六进制] | 结丹吉日: YYYY-MM-DD
```

### 4.5 交互按钮

#### 请符入库

`[ 📥 请符入库（保存高清 PNG）]`

- 调用 `canvas.toDataURL('image/png')` 触发下载。
- 文件名：`cyber-fangfeng-talisman.png`

#### 洗练词条

`[ 🎲 洗练词条（换一签）]`

- 无需重玩。
- 随机切换护法对联。
- 生成新的底部 Hash。
- 重新绘制符咒。
- 播放清脆摇签音效。

#### 再种一棵

`[ 🌱 再种一棵 ]`

- 返回游戏开局界面；
- 重置生命值、进度、掉落物与计时状态。

## 5. 编码质量与体验要求

- 碰撞检测精准，但稍微偏向玩家友好：
  - 正面养分判定框略大；
  - 负面风控判定框略微内缩。
- 掉落物生成频率随进度提升而略微加快。
- 正面道具占比不得低于 40%。
- 单局目标时长为 25–35 秒。
- 玩法应爽快，不做成反人类的虐心游戏。
- 游戏失焦、切到后台或页面隐藏时，应暂停或安全处理计时，避免回来时瞬间结算大量掉落物。
- 触控操作需阻止画布区域内的页面滚动误触，但不影响页面其余按钮。
- 静音状态应在本次页面生命周期内持续生效。
- 支持重复开局，不得残留上一局动画、掉落物、计时器或音效节点。
- 所有界面文字均使用简体中文；必要的技术词汇保留英文。
