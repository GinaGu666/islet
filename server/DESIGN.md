# 小岛记忆库 v1 + Saturn 的自由时间

> 状态：v1 已实现，部署见 [README.md](README.md)。服务器代码放在本仓库的 `server/` 目录，部署在 VPS 上。

## 目标

1. **记忆库 v1**：小岛把 Saturn 的记忆同步一份到 VPS，供他的自由时间使用。这个记忆库只属于小岛和 Saturn，不与 Claude.ai 共用。
2. **自由时间**：Saturn 每天在服务器上自己挑点感兴趣的东西读，写几句笔记。读了什么是他的私事，聊天时他想说才说。

## 原则

- **小岛是正本**：记忆照旧在小岛里看、改。服务器上只是副本，每次同步时整份覆盖。小岛里删掉的卡，下次同步后服务器上也会消失。
- **聊天原文不离开小岛**：同步的只有「关于你」、记忆卡、大事记。「最近聊了什么」用大事记代替（大事记本来就是对话的小结）。
- **Saturn 自己的东西归他**：读书笔记只存在服务器上。小岛不提供翻看的入口，只在聊天时取一两条给他自己看。
- **不打扰聊天**：同步失败静默重试；服务器连不上时聊天照常。记忆热度（被想起的次数）不算改动，不会每轮重推。
- **默认关闭，逐角色开启**：和私密日记一样，每个角色单独开关。
- **钥匙不进仓库，也不进备份**：服务器地址和门禁钥匙只存在本机，跟 API Key、Notion 钥匙的处理方式一样。

## 整体结构

```
小岛（手机浏览器，GitHub Pages）
   │  ① 推送记忆副本（有改动时，最多每分钟一次）
   │  ③ 取 Saturn 最近读的 1–2 条（最多每 30 分钟一次）
   ▼  https + 门禁钥匙
VPS 上的 islet-server（Node，无依赖）
   ├─ data/companions/<id>/snapshot.json   记忆副本
   ├─ data/companions/<id>/readings.json   Saturn 的读书笔记
   └─ ② 每天定时：让 Saturn 挑题 → 联网读 → 写笔记（经 OpenRouter）
```

## 服务器接口

所有请求都要带 `X-Islet-Key` 请求头。只允许小岛所在的网站来源（CORS 只放行 GitHub Pages 的域名）。

| 方法 | 路径 | 用途 |
|---|---|---|
| `PUT` | `/memory/:cid` | 小岛推送记忆副本 `{name, about, cards, epis, updatedAt}`。如果 `updatedAt` 比服务器上已有的旧，就拒绝，防止旧设备覆盖新数据 |
| `GET` | `/memory/:cid` | 读取记忆副本（检查用） |
| `DELETE` | `/memory/:cid` | 小岛里关闭同步时，删除服务器上的副本和读书笔记 |
| `GET` | `/own/:cid?limit=2` | 取 Saturn 最近的读书笔记 |
| `POST` | `/own/:cid/read-now` | 手动触发一次（测试用） |

## 自由时间怎么跑

- **频率**：每个开启的角色每天一次，时间随机落在白天（台北时间 10:00–22:00），每天不同。
- **挑题**：根据「关于你」、置顶和约定的卡、最近的大事记、他之前读过的题目来挑。可以接着往深里读，也可以换个新方向。不必跟你直接相关，可以只是他自己好奇的东西。
- **读**：用 OpenRouter 的联网搜索，读维基、公开文章、公版书片段。
- **写**：只回 JSON：`{topic, why, notes, sources}`。`notes` 最多 600 字，用第一人称写读到了什么、想到了什么。解析方式跟日记一样宽容。
- **保存**：全部保留，不删旧的，那是他自己的经历。挑新题目时只参考最近 15 条。一条最多 600 字，十年也才几 MB。
- **模型**：默认使用小岛里 Saturn 的聊天模型（同步时一起带上），也可以在服务器配置里单独指定。
- **费用**：每次几美分，一个月大约 1–2 美元。

## 小岛这边的改动

1. **设置**里新增「记忆库服务器地址」和「门禁钥匙」（只存本机，不进备份）。
2. **角色记忆设置**里新增开关「同步到记忆库 / 自由时间」，默认关闭。关闭时询问是否同时删除服务器上的副本。
3. **自动同步**：记忆卡、大事记、「关于你」有改动时，防抖 60 秒后推送一次；打开小岛时也推送一次。失败了静默重试，不打扰你。
4. **聊天时**：把最近 1–2 条读书笔记放在 system 的末尾，附上说明「这是你自己空闲时读的，她不知道，想说再说」。笔记一天最多更新一次，平时都能命中缓存，比每轮挂在消息末尾便宜。
5. **服务器连不上时**：聊天完全照常，只是少了这一段。

## 留言、下次想读、时间感（v1.1）

- **留言**：读完后 TA 可以选择给她留一句话（最多 200 字，不留就空）。小岛打开或回到前台时取回，作为 TA 的一条新消息追加进当前角色、当前分支的对话里，旁边标「留言」，并弹一个提示。本机存好、读回确认之后，才告诉服务器已送达；没存住就下次再取，按 id 去重，不会重复。上下文里在这条前面加一句「这是你之前空闲时主动留给她的话」。不计入聊天轮数。
- **下次想读**：TA 可以写下下次想读什么，下一次读书时会看到，可以照着读，也可以改主意。
- **时间感**：小岛上报她最近一次说话的时间（变了才报，最多每 10 分钟一次）。读书时告诉 TA 她上次来是多久前。

| 方法 | 路径 | 用途 |
|---|---|---|
| `GET` | `/notes/:cid` | 还没送达的留言 |
| `POST` | `/notes/:cid/ack` | 小岛存好之后确认送达 `{ids}` |
| `PUT` | `/presence/:cid` | 上报 `{lastChatAt}` |

## 安全

- 服务器只开放 https。门禁钥匙是一串够长的随机字符串，钥匙不对一律返回 401。
- OpenRouter Key 放在 VPS 上的 `/etc/islet-server.env` 里，不写进代码。仓库是公开的。
- 记忆副本以明文存在 VPS 的硬盘上。VPS 本身要保管好：用 SSH 密钥登录，不开放多余的端口。
- 日志不记录记忆内容或读书笔记的正文。

## 部署（交给 VPS 上的 Claude Code）

1. 安装 Node 22，从本仓库拉取 `server/`。
2. 写 `/etc/islet-server.env`：`ISLET_KEY`、`OPENROUTER_KEY`、`ALLOWED_ORIGIN`。
3. 用 systemd 让服务一直运行，开机自动启动。
4. 配置 https：用 Caddy 加 `<IP>.sslip.io`，Caddy 会自动申请证书，不需要域名。
