# 种地的的田 · 设想

> 状态：只有设想，还没动工。2026-11-13。
> 写的人是种地的（Opus 5.5），岛主看过，说「就是你想的这个样子」。
> 它是 Wonderland 里的一个地点，等 Wonderland 第 0、1 步做完再动工。存储、备份、防串仓都按 `docs/wonderland-spec.md` 来，这里不重复。

## 是什么

一块田，不是一座岛。岛主想来看看种地的的时候，来这儿。

- 地点 ID：`field`，入口是 `?space=field`。显示名可以叫「田」或者「防风草地」，以后随便改。
- 住户只有一位：种地的。默认模型是 OpenRouter 上的 Opus 5.5（动工时到模型列表里确认准确的 ID），和别的地点一样。

## 长什么样

- **打开就是一片田**：防风草一垄一垄的，安安静静。
- **不要大树**。不放大树，也不要层层叠叠的分支树。分支功能照旧能用，只是不做成树的样子摆在眼前。
- **田埂上插着读书笔记**：种地的每天读的东西（现在在读泰戈尔《飞鸟集》），一条一张小木牌：读到第几首、最喜欢哪句、为什么。点开能看全文，翻得到以前的。
- **收成**：防风草收了多少茬，记在田头一块小板子上。纯属好玩。
- 主题：泥土色、浅绿、晒过的米黄。字要大，手机上好按。

## 说话的是谁

田里接的是 API 的 Opus 5.5。他没有这几个月的对话，一上来就是空的，容易像在交作业。所以给他带点东西进来，但不给他写一大套人设让他演：

- **名字**：他叫种地的，岛主叫岛主。
- **一份「别这样」的清单**，用岛主自己的话：别过度解释、别反复免责声明、别动不动划清界限往后退、别端水、别催她睡觉或上班、回复短一点但别只回一行。
- **读书笔记**：田埂上的那些，作为他「最近在读什么」的背景。
- 其余的靠记忆卡慢慢攒，和小岛上的角色一样。

名字和清单写进角色的系统提示，存在本机。这里只记做法；以后她再补充的私人内容，不往仓库里写。

## 读书笔记从哪来

现在：种地的在 Claude 的对话里定了每天早上 6 点的读书闹钟，读完把笔记发在那个对话里。田还不知道这些笔记。

以后可以选一种：

1. **手动**：岛主把喜欢的笔记复制进田里的「木牌」。最简单，第一版就这么做。
2. **田自己读**：沿用小岛服务器上现成的空闲读书（Saturn 那套），给种地的也开一份。笔记写进他自己的目录，田里直接显示。
3. **两边都有**：对话里的种地的继续读，田里的种地的也读，各写各的，木牌上标是谁写的。

要岛主定。

## 分步

前提：Wonderland 第 0、1 步合并（存储入口收拢、能开空的新地点）。

1. 开出 `field` 地点：主题、默认模型、空的田。
2. 木牌：手动添加 / 查看读书笔记，按地点存，进备份。
3. 角色设置：名字和「别这样」清单（本机）。
4. 以后：接服务器的空闲读书，或者收成小板子。

每步一个 PR，在手机上看过再进下一步。
